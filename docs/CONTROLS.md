# Controls

Press **F1** in the game to see these on screen. Prompts change automatically between keyboard
and controller names depending on what you used last.

## Movement

| Action | Keyboard & mouse | Controller |
|---|---|---|
| Move | WASD (or arrow keys) | Left stick |
| Look | Mouse | Right stick |
| Sprint | Hold Shift | Hold RT |
| Run up a wall | Sprint into it | Sprint into it |
| Run sideways on a wall | A / D while on it | Left stick |
| Drop off a wall | Let go of Shift | Let go of RT |
| Jump (hold to leap higher) | Space | A |
| Double jump | Space in the air | A in the air |
| Glide | Hold Space while falling | Hold A while falling |
| Wall jump | Space on a wall | A on a wall |
| Dash / air dash | Q | B |
| Tether zip | C (or middle mouse) | LT |

## Fighting

| Action | Keyboard & mouse | Controller |
|---|---|---|
| Attack (combo) | Left click | X |
| Dive bomb | Left click in the air | X in the air |
| Form special | Right click | Y |
| Choose arm form | 1–7, mouse wheel | D-pad left / right |
| **Forms wheel** (pick head, arm, leg and body forms in slow motion) | Hold Alt (or hold X) | Hold D-pad up |
| Cycle body form: none / Shield / Armor / Wings / Light Body | Tap X | Tap D-pad up |
| Grab / throw | E | RB |
| Drop what you hold (or brand them as an ally, with Dominate) | Right click | Y |
| Consume | F | LB |
| Groundspike | G | Hold LB + press X |
| Tendril Barrage | T | Hold LB + press Y |
| Artillery strike (needs a military disguise) | R | Hold LB + press RB |
| With a gun: aim (rocket launcher: hold on a tank or gunship to lock on) | Hold Right click | Hold Y |
| Focus (slow motion) | Z | L3 (click left stick) |
| Cycle head form: normal / Thermal / Night Vision / Predator Sense | V | R3 (click right stick) |
| Biomass Decoy | B | D-pad down |
| Bio-Bomb (while holding someone) | B | D-pad down |
| Creature form: cycle Brute / Stalker / Wraith / human | N | Hold LB + press D-pad down |
| Hijack tank / gunship | E next to it (or Tether onto it) | RB |
| Pick up a gun | E | RB |
| Fire a gun | Left click | X |

## Driving and flying

| Action | Keyboard & mouse | Controller |
|---|---|---|
| Tank: drive / turn | W S / A D | Left stick |
| Tank: aim turret | Mouse | Right stick |
| Tank: fire | Left click | X |
| Gunship: move | WASD (relative to camera) | Left stick |
| Gunship: climb / descend | Space / Shift | A / RT |
| Gunship: missiles / minigun | Left / right click | X / Y |
| Jump out | E | RB |

## Menus

| Action | Keyboard & mouse | Controller |
|---|---|---|
| Skills | Tab or U | Back / View |
| Disguise wardrobe | I | Hold LB + press B |
| Enter a building / use something | E at a glowing door | RB |
| In menus: move / select / back | Mouse, Esc | D-pad or left stick / A / B |
| Pause menu | Esc | Start / Menu |
| Map | M | — |
| Controls | F1 or H | — |
| Fullscreen | F11 | — |
| Unstick (teleport to a rooftop) | F5 | — |
